# 원래 화면으로 돌아가는 길

이 문서는 하나만 다룬다. **어떻게 해도 유튜브가 복구된다**는 것을 어디에서 보장하고,
어디를 고치면 그 보장이 깨지는가.

## 불변식

> 확장은 페이지에 **노드 두 개**(메뉴용 쌍둥이를 더해 세 개)를 넣고,
> 유튜브의 노드는 **하나도 건드리지 않는다.**

```
<style id="oc-easy-mode">     유튜브를 가리는 스타일시트 하나
<oc-easy-mode>                내 UI 가 들어있는 섀도우 호스트
<oc-easy-mode-overlay>        메뉴·모달·토스트. 영상보다 위에 있어야 해서 따로 둔다
```

들어내면 끝이다. 저장해둔 상태가 없으니 **되돌리다 실패할 수 있는 지점 자체가 없다.**

### 예외 하나 — 오리온의 주입 스크립트

`world: "MAIN"` 을 무시하는 브라우저(오리온·사파리)에서는 `<script>` 하나를
`document.head` 맨 앞에 넣는다. 유튜브의 노드에 자식이 하나 생기는 것이므로 위
문장의 유일한 예외다. **로드되는 즉시, 실패해도 즉시 스스로 걷어낸다.** 남는 것은
없고, `e2e/02-orion.spec.ts` 가 실제로 그것을 확인한다.

### 왜 `visibility` 이고 `display` 가 아닌가

플레이어는 우리가 지우려는 것들의 **자손**이다. `display: none` 은 자손이 되살아날
방법이 없지만 `visibility` 는 있다. 그래서 이렇게 한다.

```css
body > *:not(oc-easy-mode):not(oc-easy-mode-overlay) { visibility: hidden }
#movie_player { visibility: visible; position: fixed; /* 우리 슬롯 위로 */ }
```

`display: none` 을 쓰면 `<video>` 가 렌더 트리에서 사라지고, 그때부터 유튜브가
플레이어를 두고 스스로 판단하기 시작한다.

### 왜 인라인 스타일이 아니라 우리 시트 안의 `:root` 인가

플레이어의 좌표는 커스텀 속성으로 넘긴다. 그 속성을 `document.documentElement.style`
에 쓰면 편하지만, 그 순간 **유튜브의 요소에 손을 댄 것**이 된다. 그래서 우리 스타일
시트의 첫 규칙으로 빈 `:root {}` 를 넣고 거기에 쓴다. 시트를 지우면 속성도 같이
사라지므로 정리할 것도 없다.

`e2e/00-safety.spec.ts` 가 이걸 붙잡고 있다. 루트 요소의 인라인 스타일에 `--oc-` 가
보이면 실패한다.

### `position: fixed` 보정

조상 중에 `transform`·`filter`·`contain` 이 하나라도 있으면 `fixed` 의 기준이
뷰포트가 아니라 그 조상이 된다. 유튜브가 언제 그런 걸 넣을지 모르므로 **추측하지
않는다** — 놓고, 재고, 어긋난 만큼 `translate` 로 되민다. 한 프레임에 수렴하고,
슬롯이 움직일 때마다 다시 잰다 (`src/main/shell.ts` 의 `apply`).

## 나가는 길 세 가지

| 길 | 언제 | 코드 |
|---|---|---|
| 사이드바 버튼 · 툴바 스위치 | 평소 | `index.ts` 의 `leave(true)` |
| **Esc 두 번**, 1초 안에 | UI 가 깨졌을 때 | `shell.ts`, `document` 의 캡처 단계 |
| 워치독 8초 | 화면이 아예 안 떴을 때 | `shell.ts`, `place()` 가 살아있음을 보고 |

캡처 단계에 거는 이유는 유튜브 자신의 단축키 처리와 우리 UI 보다 **먼저** 받기
위해서다. Esc 한 번은 일부러 남겨둔다. 메뉴를 닫고 입력창에서 빠져나오는 키를
가져가면 그것이 또 하나의 덫이 된다.

## 주소창 — 유일하게 "정리"하는 것

우리는 이동하지 않고 플레이어에게 **다음 곡을 지시**한다(`loadVideoById`). 그래서
주소창은 모드에 들어올 때 열려 있던 영상에 머문다. 그대로 나가면 주소와 재생 중인
영상이 다른 페이지를 넘겨주게 되므로, **어긋나 있을 때만** 재생 중인 영상의
watch 주소로 이동한다. 같으면 이동하지 않는다.

## 이 문서를 무효로 만드는 변경

- 유튜브의 노드를 옮기거나(`appendChild` 로 플레이어를 우리 트리에 넣는 것 포함)
  속성·클래스를 쓰는 것
- `document.documentElement` 나 `body` 에 클래스·인라인 스타일을 붙이는 것
- 워치독을 끄거나, 실패 경로에서 `teardown()` 없이 예외를 삼키는 것
- Esc 한 번을 가져가는 것

넷 중 하나라도 하고 싶으면, 먼저 `e2e/00-safety.spec.ts` 를 고칠 수 있는지 보라.
못 고치면 하지 않는 게 맞다.
