이지 모드

유튜브를 음악과 영상 플레이어로 사용하는 확장 프로그램입니다. 화면 구성은 이 확장이 맡고, 재생은 유튜브가 그대로 합니다.

내려받기 GitHub

스토어에는 등록하지 않습니다. 같은 파일을 세 브라우저에서 사용합니다.

주요 기능

유튜브의 화면 대신 이 화면이 뜹니다. 데이터와 재생은 그대로 유튜브의 것입니다.

둘러보기

선반 형태의 첫 화면입니다. 로그인하지 않아도 항상 채워져 있습니다.

대기열과 재생목록

셔플, 반복, 라디오를 지원합니다. 재생목록을 만들고 편집합니다.

음악 모드와 영상 모드

같은 목록을 트랙 목록 또는 큰 썸네일 격자로 표시합니다.

쇼츠 제외

세로 영상은 어느 목록에도 표시하지 않습니다.

방향키 조작

리모컨처럼 방향키로 이동하고 Enter로 선택합니다.

유튜브 플레이어 재생

유튜브의 플레이어가 그대로 재생합니다. 파일을 내려받지 않습니다.

화면

모드를 바꾸면 같은 목록이 그 자리에서 다시 그려집니다.

설치 방법

스토어를 거치지 않습니다. 받은 파일을 브라우저에 직접 넣어 주세요.

오리온 (맥 · 아이폰 · 아이패드)

  1. 위의 내려받기 버튼으로 zip 파일을 받아 주세요.
  2. 설정 → 확장 → + 를 눌러 받은 파일을 선택해 주세요.
  3. 주소창 옆 아이콘을 눌러 켜 주세요.

크롬 · 엣지

  1. zip 파일을 받아 압축을 풀어 주세요.
  2. chrome://extensions 에서 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드를 선택해 주세요.
  3. 압축을 푼 폴더를 지정한 뒤 툴바 아이콘을 눌러 주세요.

원본 화면 복귀

이 확장은 유튜브의 DOM을 변경하지 않습니다. 스타일시트 하나와 자체 화면 하나를 덧씌울 뿐이며, 종료는 복원이 아니라 그 둘을 제거하는 과정입니다. 되돌릴 상태가 없으므로 복원에 실패하는 경우도 없습니다.

사이드바의 유튜브로 돌아가기

평소에 사용하는 방법입니다. 툴바 스위치로도 같은 일을 합니다.

Esc Esc

1초 안에 두 번 누르면 어느 화면에서나 즉시 빠져나옵니다.

8초 감시

화면이 8초 안에 표시되지 않으면 확장이 스스로 물러납니다.

제한 사항

할 수 없는 것과 하지 않는 것입니다.

아이폰 화면 잠금 재생

이 확장이 제공하지 않습니다. 구글이 서버에서 차단하고 있어 확장으로는 해결할 수 없습니다. 브라우저의 백그라운드 재생 기능을 사용해 주세요. 오리온과 파이어폭스가 그 기능을 제공합니다.

구독 · 시청 기록 · 내 재생목록

유튜브 로그인이 필요합니다. 검색과 둘러보기는 로그인 없이 동작합니다.

광고 차단

포함하지 않습니다. 사용하던 차단기를 그대로 함께 켜 주세요.
