심플하고 쉬운 유튜브 재생기

유튜브 화면을 심플하고 쉬운 재생기로 완전히 바꿔 드립니다. 음악과 영상을 한자리에서 다루며, 재생과 스트림은 유튜브가 그대로 맡습니다.

내려받기 GitHub

오리온, 크롬, 엣지 브라우저에서 모두 동일한 파일을 사용합니다.

기능 안내

핵심 기능 구성

복잡한 추천 피드 대신 정갈한 플레이어 화면을 제공합니다. 데이터와 재생은 유튜브가 그대로 맡고 화면만 바꿉니다.

둘러보기

선반 형태로 구성된 첫 화면입니다. 유튜브 계정에 로그인하지 않으셔도 비어 있지 않고 음악과 영상 목록을 바로 탐색하실 수 있습니다.

대기열과 재생목록

재생 중인 대기열 목록을 자유롭게 확인하고 순서를 관리합니다. 무작위 재생, 반복 재생 기능과 함께 맞춤 재생목록을 간편하게 다룹니다.

음악 모드와 영상 모드

가벼운 감상을 위한 트랙 줄 목록 형태와 큼직한 화면 감상을 위한 영상 썸네일 격자 형태를 버튼 하나로 자유롭게 오가실 수 있습니다.

쇼츠 없음

몰입을 방해하는 세로형 쇼츠 영상을 모든 화면과 탐색 목록에서 완전히 제외하여 정갈한 감상 환경을 유지합니다.

방향키 조작

마우스 없이도 거실 TV를 다루듯 키보드 화살표 방향키로 항목을 이동하고 실행 키를 눌러 손쉽게 제어하실 수 있습니다.

데스크톱과 모바일

오리온, 크롬, 엣지 등 데스크톱 웹 브라우저는 물론, 모바일 오리온 브라우저에서도 동일하게 작동합니다.

설치 가이드

브라우저별 설치 방법

내려받으신 파일을 브라우저에 등록해 주세요. 별도의 복잡한 과정 없이 1분 안에 설치하실 수 있습니다.

오리온 브라우저

  1. 상단의 내려받기 단추를 눌러 압축 파일(zip)을 받아 주세요.
  2. 브라우저 메뉴에서 설정 → 확장으로 이동하신 후 + 단추를 눌러 해당 zip 파일을 선택해 주세요.
  3. 주소 표시줄 우측의 확장 프로그램 아이콘을 눌러 켜 주시면 완료됩니다.

크롬 및 엣지 브라우저

  1. 내려받으신 압축 파일(zip)을 원하시는 폴더에 풀어 주세요.
  2. 주소창에 chrome://extensions 를 입력하여 이동하신 후, 우측 상단의 개발자 모드를 켜 주세요.
  3. 좌측 상단의 '압축해제된 확장 프로그램을 로드합니다' 단추를 눌러 압축을 푼 폴더를 지정해 주세요.

안내 사항

이용 시 알아두실 점

원활하고 투명한 이용을 위해 확장의 동작 방식과 범위를 미리 안내해 드립니다.

Esc 두 번으로 언제든 종료
유튜브의 본래 구조를 훼손하지 않습니다. 키보드의 Esc 키를 1초 안에 두 번 누르시면 언제든지 확장을 닫고 본래의 유튜브 화면으로 즉시 되돌아옵니다.
화면 잠금 재생은 브라우저 기능 사용
기기 화면이 꺼진 상태에서의 재생은 확장이 직접 제어하지 않으며, 오리온 브라우저 등이 자체적으로 지원하는 백그라운드 미디어 재생 기능을 활용합니다.
광고 차단 없음
유튜브 스트림 규정을 준수하며 광고 차단 기능을 내장하지 않습니다. 기존에 사용하시던 차단 확장 프로그램이 있으실 경우 그대로 함께 켜 두시면 됩니다.
구독과 기록은 로그인 필요
검색과 기본 둘러보기는 로그인 없이도 자유롭게 이용하실 수 있습니다. 다만 개인 구독 채널 목록, 시청 기록 및 보관함 재생목록을 불러오시려면 유튜브 로그인이 필요합니다.
